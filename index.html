? Setup Guide

1. Clone the Repo & Fetch Notebooks

git clone <repo-url>
cd Notebooks
python fetch_notebooks.py list.txt .

This downloads all notebooks and their dependencies. You only need to do this once (or re-run to reset notebooks to their original state).

2. Install Jupyter

Check if Jupyter is already installed:

jupyter --version

If not found, install via pip:

# JupyterLab (recommended — modern interface)
pip install jupyterlab

# Classic Notebook
pip install notebook

Verify after installing:

# Should print a version number
jupyter lab --version
jupyter notebook --version

3. Start the Jupyter Server

Open a terminal, cd into the Notebooks folder, and start Jupyter:

cd path/to/CS4248/Notebooks

# Option A — JupyterLab
jupyter lab

# Option B — Classic Notebook
jupyter notebook

This launches a local server (usually at http://localhost:8888) and opens a browser tab. If the port is different (e.g. 8889), update the Base URL field above to match.

4. Use This Page

  1. Make sure Jupyter is running (step 3).
  2. Select JupyterLab or Classic Notebook in the dropdown above, matching whichever you started.
  3. Click any notebook title — it opens directly in your running Jupyter server.
  4. The yellow Colab button opens the original GitHub version in Google Colab (no local setup needed, but local data files won't be available).

Troubleshooting

  • Notebook shows raw JSON? — Jupyter isn't running, or the Base URL is wrong.
  • "File not found" in Jupyter? — You started Jupyter from a different folder. Restart it from the Notebooks/ directory.
  • Port conflict? — If 8888 is in use, Jupyter picks the next available port (8889, 8890...). Check the terminal output and update the Base URL.
